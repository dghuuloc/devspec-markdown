# Changelog

## 0.0.2

- Improved PDF browser auto-detection for another-machine installations.
- Added detection for Edge, Chrome, Brave, and Chromium from common install paths.

- Improved PDF export handling for long file paths and long code blocks.
- Improved code block spacing and trailing blank-line handling.
- Improved README documentation for Marketplace release.
